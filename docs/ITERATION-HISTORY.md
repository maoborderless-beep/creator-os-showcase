# 迭代与证据边界

| 阶段 | 已记录的增量 | 已记录的验证及边界 |
| --- | --- | --- |
| P0 | 读取保护、备份与恢复路径 | 异常时不自动创建空工作区；不把代码仓库当备份。 |
| P1.3-A | 灵感分类、多标签、搜索筛选 | 266 项测试；Chrome 与 WKWebView 使用合成数据验证。网络模拟不代表实网抓取成功。 |
| P1.3-B | 重复提醒与安全保存 | 用户决定是否继续收藏；不自动合并。 |
| P2-A / 0.2.0 | 导航、主题与入口 | 352 项测试；独立 Chrome 和 WKWebView 综合场景，保留旧工作区兼容。 |
| P2-B | 独立任务、今日待办和日程 | 合成环境交互与并发保护验证；任务不自动创建内容等业务记录。 |
| P2-B.1 / 0.2.2 | 任务界面打磨 | 记录 17 项专项检查通过及隔离双引擎验证。 |
| 0.2.3 | 主题字体、响应式和菜单修整 | 阶段记录 447 项测试及 lint、类型检查通过；正式原生菜单曾出现视觉阻断并回滚，后续重试和正式安装有不同验收范围，不能宣称外部 Beta 通过。 |
| P2-B.3 | 任务控件和 Glass 标题修整 | 私有分支的隔离验证；日期选择器是原型，未作为正式日期输入交付。 |

各数字来自相应阶段记录，不代表当前演示构建重新运行的结果。自动化、合成数据、正式实机及用户验收不能互相替代。当前没有公开可下载安装包，也未完成外部 Beta。
